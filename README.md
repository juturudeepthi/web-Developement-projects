WEB DEVELOPMENT PROJECTS

PROJECT - 1 : RJ Technology Training Institute Website (HTML, CSS)

Algorithm:
1. Start by creating multiple HTML documents:
    Home.html, About.html, Contact.html, Frontend.html, Backend.html, Apply.html, and OnlineTraining.html.
2. On each page, add a common navbar with the site name "RJ Technology" and links to Home, About, Courses, Online Training, and Contact.
3. In Home.html, add an offer banner, a hero section with an animated background and an "Apply Now" button, a "Key Features" section, and an "Our Courses" section with course cards.
4. In About.html, add sections for "Our Story", "Mission & Vision & Values", "Meet Our Team", and "Why Choose Us".
5. In Contact.html, add a "Contact Details" section and a "Send a Message" form.
6. In Frontend.html and Backend.html, add course info, an enroll button, and an expandable syllabus using details tags.
7. In Apply.html, add a registration form with fields like name, age, mobile number, email, and password.
8. In OnlineTraining.html, add a list of online courses, an instructor section, and student testimonials.
9. Add popup forms (Apply Now, Enquiry, Enroll) on relevant pages using the CSS `:target` selector.
10. Style all pages using CSS with Flexbox, Grid, hover effects, and animations.
11. Add a common footer with contact info and social media links on every page.
12. Test the website by clicking through all pages, links, popups, and dropdowns.
